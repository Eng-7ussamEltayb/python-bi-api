# API مؤشرات الأعمال
## Python BI KPI API

**Portfolio Demo Project** | المستوى: **متقدم** | المؤلف: [Eng-7ussamEltayb](https://github.com/Eng-7ussamEltayb)

### الفكرة
واجهة API تقدم مؤشرات KPI جاهزة للوحات Power BI/الواجهات الأمامية.

### التقنيات
Python, Flask, pandas

### المميزات
- إجمالي الإيرادات
- أوامر العمل المغلقة
- متوسط MTTR
- تجميع حسب المنطقة

### طريقة التشغيل
1. pip install -r requirements.txt
2. python app.py
3. افتح http://127.0.0.1:5000/api/kpis

### هيكل المشروع
```
app.py
data/kpis.csv
requirements.txt
README.md
```
